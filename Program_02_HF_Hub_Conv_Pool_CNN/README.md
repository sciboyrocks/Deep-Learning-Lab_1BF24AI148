# Lab Program 2 — Hugging Face Hub, NumPy Convolution & Pooling, CNN on CIFAR-10

**Problem statement:** Introduce the Hugging Face Hub, dataset loading, and model cards. Implement convolution and
max-pooling using NumPy. Explore kernel size, stride, and padding, and build a basic CNN for CIFAR-10 classification.

## Files

| File | Contents |
|---|---|
| [`Program2_HF_Conv_Pool_CNN.ipynb`](Program2_HF_Conv_Pool_CNN.ipynb) | The full program, executed, with all outputs and plots |
| [`MODEL_CARD.md`](MODEL_CARD.md) | Hugging Face model card generated by the notebook for the trained CNN |

## What the notebook covers

**Part A — Hugging Face Hub**
- Searching models and datasets with `HfApi` (`list_models`, `list_datasets`, `model_info`)
- Reading a model card (`ModelCard.load`) and a dataset card (`DatasetCard.load`): YAML metadata + Markdown body
- Loading CIFAR-10 with `datasets.load_dataset("uoft-cs/cifar10")`, inspecting features / class names,
  `select`, `filter`, `train_test_split`, `with_format("numpy")` and streaming mode

**Part B — Convolution and max-pooling in NumPy**
- `conv2d_loops` / `maxpool2d_loops`: explicit-loop implementations (multi-channel, multi-filter, stride, padding, bias)
- `conv2d` / `maxpool2d`: vectorised im2col versions using `sliding_window_view` + `einsum` (batched)
- Verified against `torch.nn.functional.conv2d` / `max_pool2d` for many settings; speed comparison
- Hand-crafted kernels (blur, sharpen, Sobel, Laplacian) applied to a CIFAR-10 image

**Part C — Kernel size, stride and padding**
- Output size formula `floor((n + 2p − k) / s) + 1`, checked against the implementation
- Visual experiments for each hyper-parameter, "same" padding, parameter counts and receptive field

**Part D — Basic CNN for CIFAR-10 (PyTorch)**
- 3 VGG-style blocks `[Conv3×3 → BN → ReLU]×2 → MaxPool → Dropout` (32/64/128 channels) + 2 FC layers
- Data augmentation (random crop + flip), SGD + One-Cycle LR, label smoothing
- Loss/accuracy curves, confusion matrix, per-class accuracy, sample predictions
- Visualisation of learned first-layer filters; the NumPy `conv2d` reproduces the trained layer's output

**Part E — Model card for our own model** written with `huggingface_hub.ModelCard` using the real results
